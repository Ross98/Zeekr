# 仓库隐私边界

仓库只保存源代码、公开第三方资源与许可证、通用文档、部署模板和离线测试。

以下内容保留在本机并通过 `.gitignore` 排除：

- `Myconfig.md` 等原始实车记录及个人验收报告。
- `zeekr_control/vehicle_profiles.json`。仓库提供 `vehicle_profiles.example.json` 通用模板。
- 会话与 Token JSON、环境文件、密钥、日志、抓包、数据库和本地截图目录。
- `private/` 下的原始文档备份。

应用运行数据默认位于用户应用数据目录，不属于项目仓库。会话和数据库是受文件权限保护的本机明文，不是加密存储。

显式选用 macOS 钥匙串后，只有 refreshToken 值进入当前 uid 的本机 login 钥匙串，不同步到 iCloud，不通过 shell 参数、日志、HTTP 健康信息或数据库保存。原有 accessToken 保持兼容会话文件的 600 权限存储；session 与暂存候选只记录续期 Token 的引用和指纹。默认登录仍不捕获 refreshToken，其他平台不自动降级为明文续期存储。钥匙串锁定、缺项目、权限拒绝或引用不匹配时安全拒绝刷新，原有受保护读取可继续。

state 备份包含只读凭据、引用及禁重放意图，不包含钥匙串内的 refreshToken；备份不是完整钥匙串恢复包。恢复到缺少原钥匙串的机器时，须重新短信认证，不能把旧会话或占位记录当作刷新授权。详见 [操作与恢复边界](macos-keychain-refresh.md)。

测试中的 VIN、手机号、令牌、坐标和车辆观测均为合成数据；固定时间使用测试时间线。测试不访问真实车辆。车型图片来自公开官方素材，授权边界见 `THIRD_PARTY_NOTICES.md`。

客户端中的 GW1/GW2 签名常量来自该文件列明的公开社区版本，不是个人账号凭据。个人访问令牌、手机号、服务器地址和本机用户名不得写入源码、文档或提交说明。

上传前应检查实际暂存文件而不只检查工作目录，并检查提交作者邮箱；可使用 GitHub noreply 邮箱减少个人信息披露。`.gitignore` 不会移除已进入 Git 历史的内容，新增敏感文件前仍需检查。发现真实凭据已上传时，应撤销凭据并清理历史。
