# 多边形地点区域

在“行程标签”的地点管理中，新建多边形地点，按住鼠标左键沿边界连续圈画，松开后自动闭合；命名并预览影响行程，再保存。圈画时地图不会随鼠标平移，浏览地图可切回平移模式。也可选择逐点绘制。顶点可拖动；也可选择顶点后删除、撤回最后一个点或重新绘制。逐点模式中，键盘可平移地图，再用“将地图中心加入边界”添加顶点。圈画会整理细小鼠标抖动，保存不超过 100 个可调整顶点；小点击或直线不会创建区域。按 Esc 可取消当前圈画，原区域保留。

地点标签按账号和车辆保存在现有个人记录库中，跨月持续生效。可信的行程出发、到达点落在区域内或边界上，就使用该名称；区域内多个点共享出发、到达及路线分组。后续查询重新解释历史和新增行程，不改写原始坐标或行程记录。已有单趟地点人工修正仍优先。

允许凹多边形，需 3–100 个不同顶点。自交、重复顶点、共线和无效坐标会被拒绝。地图沿用现有高德底图和 WGS84 坐标转换，地图底图只在打开时加载；服务端直接按保存的区域计算，不调用外部地址服务。

地图显示本月实际起止点与已保存区域，支持检查定位漂移。范围外的点不会因为邻近而自动扩张匹配。涉及多边形的重叠区域在预览中提示，保存时拒绝；边界接触也算重叠，避免一个边界点具有两个标签。旧圆形区域和既有圆形重叠的最近中心规则保留。

“已保存地点区域”不依赖当月是否有行程。可编辑名称和边界、恢复自动名称、撤销最近的地点操作。保存使用版本和预览令牌检查；几何、名称、历史端点或已保存区域变化后，需要重新预览。

验证：几何与命名逻辑覆盖凹形内外、边界、非法图形、圆形/多边形重叠、跨月命名、账号隔离、原始数据保护、空月份管理和撤销。桌面浏览器覆盖连续圈画、松开自动闭合、取消、逐点绘制、拖动、删除、预览失效、冲突禁存及旧圆形编辑。尚未部署，未进行已登录生产验收。
