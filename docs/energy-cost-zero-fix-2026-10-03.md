# 用电成本零值修正 · 本地

用户反馈上线估算均为零。线上只读诊断定位两处问题：有效片段充电被完整性条件整体排除，实际金额和计量虽已补充仍无法建立价格；有效零耗电片段与价格未知耗电混合汇总为零，误导成当日零成本。

修正：

- 片段充电在起止、电量、容量、时间均有效，且具有实际费用和有效桩端电量时，按账单桩端单价为有效补入电量建立参考库存。未观测到的补入电量仍未知，不分摊整单费用到片段，不假定完整充电损耗。
- 混合库存携带损耗未计全标记，随按比例消耗和重置更新；页面明确说明。完整充电仍用实际费用分摊到电池补入量，含充电损耗。
- 只有零耗电片段可估、正耗电价格未知时，日/月成本显示未知；真实已知免费电量和有效零值仍保留，部分成本不冒充总成本。
- 页面成本完全未知时显示“成本未知”；有效零 SOC 下降说明不等于实际没耗电。

纯逻辑回归先复现两个失败，再修复。修正模块在内存中只读正式数据试算，正成本能恢复，混入未知耗电的零日汇总消除；未改正式代码、账本、配置，未请求车辆或发送通知。

本地全量 Python 777 项通过；日历成本合成浏览器通过。未提交、未重新部署。
