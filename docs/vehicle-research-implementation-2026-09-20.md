# 用车研究：实现与验收

本轮先完成设计、实现、测试；用户随后明确授权 commit、部署，已于 2026-09-20 23:13:27 上线。详见 [发布记录](vehicle-research-release-2026-09-20.md)。复用已有十二项工具，新增「数据利用」作为逐字段研究入口。

## 信息结构

数据利用分为总览、字段详情、场景三个层次。总览按同一时间范围列出全部公开字段，搜索、分组、用途筛选后进入字段详情；场景面板复用同一套有效样本。参数字典维护人工解释，实验室冻结证据，通过字段路径与实验 ID 串联。

## 验收要求

- R01：217 项公开字段都有去向；目录数、实际返回数、有效时间样本数、参与分析字段数使用独立分母。私有字段仅说明处理原则，不进入公开响应。
- R02：读取范围 1–31 天，仅访问当前账号和车辆的本地归档。空范围、未来、无归档、破损归档、超过上限均有明确结果；不增加车辆请求。
- R03：按读取统计缺失、空值、无效、待核实、已解释；新时间、重复、同时间修订、异常分开统计。物理统计只用时间有效的规范样本，同时间取最后一次有效修订；倒退与重访旧时间不扩大样本量。
- R04：每字段展示首末返回、变化数、数值范围/均值、原值分布、来源时间、用途、未使用原因、适用性。数值但含义待核实的字段只做原值统计，不断言单位或意义。档案字段只作当前配置背景，明确历史未归档。
- R05：详情提供离散历史点、原值状态分布、数值分布、变化边界、按行驶/充电/停车/未知分组。缺失和时间异常不连线；缩减点数明确标注并保留桶内极值。状态边界只是观测区间，不冒充精确变化时刻或持续时长。
- R06：座舱、四轮、低压电池、门窗灯光座椅、行程充电五类场景均提供分析入口与样本覆盖。四轮差异仅来自同一有效快照；温度使用独立时间，陈旧温度排除。行程充电关联可见事件，缺失起点、排除统计和部分记录不冒充完整比较。
- R07：字段详情可选择前后样本进入实验室；已存实验可逐字段打开历史和人工核实。人工核实保存验证过的实验摘录关联，禁止跨账号/车辆/字段绑定；确认仍由用户填写，不改变运行时解码。
- R08：说明归档、档案、行程充电、人工解释、实验、费用和规则各自用途；陌生字段只统计数量，原始路径和值不出私有归档。
- R09：新查询不长期占用应用全局锁；返回前复核账号和车辆。前端请求序号隔离、失败保留筛选、账号切换清空旧数据；桌面、手机、200% 缩放、键盘与深浅主题可用。
- R10：单元测试覆盖数值与状态、重复修订、缺口与时间、隐私隔离、事件排除及证据关联；浏览器验收完整研究流程；全量 Python 回归与已有研究 UI 回归通过后完成。

## 数据口径

历史按采集日期选取，统计时间为车辆或字段时间。重复读取保留在质量统计中；分析样本去除时间异常后按车辆时间取最后有效修订。缺值仍计入分母，观测样本不是行程/时长权重。字段温度时间另外去重和验证。枚举与布尔的原值类型保持区分。分布最多显示前 20 项，其余合并计数；历史图最多 600 点、变化列表最多 100 条，完整计数保留。

场景比较仅描述共同观测，不表示因果、健康诊断或适用配置已确认。人工注释独立展示，不作为数值转换代码执行。

## 使用边界

- 每次 1–31 天，归档读取上限沿用 50,000 条；超限拒绝，不能静默截断。图表最多 600 点，完整计数与统计保留；分布保留最先出现的 20 种原值并按计数排列，其他原值明确计数。未登记路径最多计数 10,000 项，达到上限显示“至少”。
- 车辆时间原始样本在范围外、范围内仅有重复或修订时，不虚增新车辆时间样本。档案仅有当前背景，没有伪造历史。缺样字段保留在总览；场景可展开缺样清单。
- 大范围完整字段分析可能需要数分钟。前端显示真实等待时长并允许切换其他工具，查询不会长期占用应用全局锁。5,000 条合成观测测得稀疏字段约 4.3 秒、192 项历史字段约 13.9 秒（收整前测量，非生产性能承诺）。
- 所有自动化与截图使用隔离的合成数据；不表示真实车辆已返回全部 217 项、解释已核实或数据已连续覆盖。
