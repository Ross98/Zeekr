# 用车日历：回顾与补账

已确认：先按天回顾和补账，再看整月规律。延续现有极氪配色、字体与深浅主题；以紧凑月历和当日时间线为主体，减少空白与重复计数。

1. 先测数据口径：月内结束事件去重汇总；每日里程按结束日；实际花费按账单日期，未知不变零；未关联或缺实际金额的充电均可补。
2. 读取已有地点命名和账本，不查询车辆/地图服务，不暴露坐标。保留跨午夜、片段、采集覆盖语义。
3. 月摘要直接切换里程/花费/待补视图；选一天看时间线；在日历内补充电金额，保留其他账单字段，保存后刷新摘要。并发修改或账号切换拒绝写入。
4. 月份、选中日和显示模式写入导航 URL；仅在用户切月或读取时查询。手机点日期展开当天，桌面并列查看。
5. 合成浏览器验证保存、未知/零、跨月、错误、焦点、响应式和主题；完整回归后收尾。不提交或部署，等待单独指令。

## Direction contract

THESIS: 月历是回顾与补遗漏的索引，日格不承担长说明。
OWN-WORLD: 沿用极氪深绿、暖色充电标识、已有纸面与夜间主题，数值对齐，真实操作优先。
STORY: 看本月 → 找一天 → 读时间线 → 补金额 → 回到同一天。
FIRST VIEWPORT: 月份工具条、单行月摘要、左月历右当日回顾；手机紧凑月历后紧邻选中日。
FORM: 已确认的月历与时间线结构，色彩标记仅表达已有记录和待处理。
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
