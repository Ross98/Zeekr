# 通勤地点自动标注设计

## 目标与范围

用户在“行程与轨迹 → 行程标签”中，对照实际地图点选“家”和“公司”。之后完成的行程，若起点、终点分别落在两个地点的范围内，自动追加“通勤”标签；返程同样匹配。用户可在地图上调整两个圆的半径，初始均为 300 米，允许 100–1000 米。现有手工标签、备注、比较和筛选继续使用。

本功能只处理当前账号、当前车辆的本地已结束行程。不搜索地址，不发送位置给新的地理服务，不自动修改历史行程，不触发车端请求或通知。

## 设计选择

采用“读取标签页时补做自动判定，并持久记录结果”。监控进程没有网页登录账号的个人记录作用域，因此不在监控进程内写账号标签。新行程结束后，用户首次读取对应月份的标签页时完成判定；界面说明这一时机。对已判定行程保存匹配或不匹配的决定，规则修改后也不重算旧行程。

其他方案：在监控进程中保存标签会引入账号与后台进程的绑定；每次查询临时计算会使规则修改影响旧行程，也无法稳定保留手工移除的结果。本设计避免这两种行为。

## 设置界面与规则

标签页顶部增加“通勤自动标注”卡片。用户先选择当前车辆，再在现有地图上点选两个中心点；地图画出两个独立、可拖动的圆。每个半径可在 100–1000 米调整，初始为 300 米。保存前显示两个范围和说明；坐标或半径无效时拒绝保存。页面提供暂停、恢复、修改和删除。删除停止后续判定，既有标注保留。

规则按账号与车辆隔离。规则保存时间是生效时间；只判定结束时间严格晚于该时间的行程。规则的每次保存、暂停、恢复、删除形成一个生效版本，版本含地点、半径、状态和生效时间。行程使用其结束时间对应的版本，避免日后修改范围时重算旧行程。版本按服务端时间排序；同一毫秒的更新由递增版本号定序。每车只保留一条通勤规则，但保留必要的历史版本供旧行程解释。

## 地点证据与匹配

仅用本地轨迹数据库中的原始位置采样，不把首个/末个可见地图点直接当作真实起止点。行程必须是已结束记录，且起止时间有效。分别在开始后 180 秒内、结束前 180 秒内找时间最近的采样；采样须有有效缓存状态时间、`trusted=true`、`plottable=true`、WGS84 坐标，且落在该行程时间窗内。任一端没有合格采样即不自动标注。两端使用球面距离计算，距离小于等于对应半径即在圆内。家到公司、公司到家都可匹配；家到家、公司到公司不匹配。部分行程只有两端证据都合格时才可匹配；不得用中途点替代缺失的端点。

本功能沿用项目现有坐标解释。车端坐标系标识未确认、GCJ-02 或位置不可信时不猜测、不转换。地图显示圆形边界及“位置采样可能存在误差”；300 米是用户可调阈值，不是车辆 GPS 精度保证。

## 数据与人工操作

私人数据库新增通勤规则版本与逐行程自动判定记录，键含账号作用域、车辆与行程 ID。每个判定记录规则版本、匹配结果、证据时间与距圆心距离，不存整条路线。原有 `tags` 集合继续保存手工标签和备注。查询将自动“通勤”与手工标签合并展示，并标明“自动”；同一标签只显示一次。手工添加的其他标签与备注永不覆盖。

用户在单趟行程中取消自动“通勤”时，保存该行程的人工排除决定；以后读取或修改规则都不补回。再次手工加入“通勤”则按手工标签保留。删除原有手工标签记录不删除自动判定；界面明确区分“删除手工标注”和“取消本趟自动通勤”。自动判定与人工排除不提供批量回填或批量撤销。

读取月份时只判定该月尚未判定、结束时间在规则生效后的行程。每趟最多读取有界的起止采样，使用现有查询范围和数量上限；不能因一个损坏的行程中止整月读取。判定及结果保存要幂等；账号、车辆切换或规则版本变化时中止旧请求，服务端写入受当前会话及车辆上下文保护。数据库事务保证重复读取不会重复写入或覆盖人工排除。

## 接口、隐私与失败处理

在现有私有标签 API 下扩展规则读取、保存和暂停等操作；所有写入继续要求登录、同源校验、当前 `insights_context` 和版本检查。规则中心坐标仅在已认证的当前车辆响应中返回。日志不写坐标、路线或地址。沿用现有地图瓦片；不引入地址搜索、逆地理编码或新第三方请求。

规则或判定保存失败时，显示错误并保留输入；不显示“已自动标注”。轨迹库不可读、位置不足或坐标系不符时，行程保持未标注，并在详情显示简短原因。暂时性读取错误不写成永久“不匹配”，下次可重试。对边界、账号隔离、逆向匹配、缺失/不可信采样、规则修改、人工移除、重复读取及并发写入做服务端测试；浏览器测试覆盖选点、圆形边界、半径调节和标签来源显示。

## 验收

用户能在真实地图上看到并调整两个 300 米圆；保存后，新结束的往返行程在首次读取标签页时自动出现“通勤”。其他方向、边界外或证据不足的行程不自动标注。人工移除后不反复补回；更改或暂停规则不改变旧行程结果。账号和车辆切换后看不到另一作用域的地点或判定。
