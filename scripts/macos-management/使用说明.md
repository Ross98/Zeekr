# Zeekr 管理

这里是 Zeekr 的独立管理入口。实际代码、数据库、账号配置、日志和备份仍保存在内置盘 `~/Library/Application Support/ZeekrServer`；本次未迁移运行文件，也未修改自启或网络配置。

## 日常使用

双击 `.command` 文件，在 macOS 终端运行。不需要 sudo。首次若 macOS 显示来源或安全提示，先核对文件来源与内容；这些入口是本次创建的本机管理工具。

| 入口 | 作用 |
|---|---|
| `01_打开网页.command` | 打开当前服务设置中的私网 HTTPS 入口；本机也可访问 `http://127.0.0.1:18765/` |
| `02_查看状态.command` | 只读查看实际版本、四个后台任务与入口，不重启 |
| `03_健康检查.command` | 只读检查任务、进程目录、资源心跳、双入口认证和车型图片；不主动刷新车辆、不发测试通知 |
| `04_打开日志.command` | 打开原日志目录；日志可能含私有运行信息，分享前先检查 |
| `05_启动服务.command` | 启动未加载的 Zeekr 任务，并检查健康；已运行任务保持原样 |
| `06_停止服务.command` | 输入“停止”后，停止本套 Zeekr 的全部任务 |
| `07_重启服务.command` | 输入“重启”后，先确认任务及子进程退出，再启动并检查 |
| `08_打开备份.command` | 打开现有备份目录；不会自动创建或删除备份 |
| `09_打开运行目录.command` | 打开实际运行根目录，方便查看各类文件 |
| `10_回退上一版本.command` | 显示当前与目标版本，输入“回退”后使用原生发布工具执行；保留最新业务数据 |
| `11_查看发布说明.command` | 打开当前版本的 macOS 发布文档 |
| `12_修改网页密码.command` | 复用原交互密码工具，密码只在本机终端输入；只请求重启网页任务 |

停止、重启、回退、改密码会改变运行状态，仅在你需要时使用。本次整理没有执行这些动作。停止是当前会话的停止，不会删除登录自启配置；下一次用户登录仍会按原配置启动。

健康检查可能等待资源巡检的新心跳，最长约 75 秒。入口报错或停止未完全确认时，先查看状态和日志，不要另开终端手动运行第二套采集或通知进程。

## 管理范围

- `local.zeekr.web`：网页。
- `local.zeekr.monitor`：采集与通知。
- `local.zeekr.reports`：周期报表。
- `local.zeekr.resources`：资源巡检。

启停逻辑从当前实际版本加载原生管理工具，沿用其发布锁、子进程退出确认及回退保护。这里没有复制一套旧版业务代码。后续若发布工具接口发生不兼容变化，入口会报错并停止操作，应先更新管理适配器。

## 文件位置

| 内容 | 实际位置 |
|---|---|
| 当前代码 | `~/Library/Application Support/ZeekrServer/current` |
| 历史版本 | 同目录 `releases/` |
| 业务数据与账号配置 | 同目录 `state/` |
| 日志 | 同目录 `logs/` |
| 备份 | 同目录 `backups/` |
| macOS 自启文件 | `~/Library/LaunchAgents/local.zeekr.*.plist` |
| 管理脚本 | 本目录 `管理工具/` |
| 整理时的版本快照 | 本目录 `部署记录/` |

`服务信息.json` 记录布局；部署记录是建立目录时的快照。实际运行状态始终以“查看状态”的结果为准。

## 自检

管理工具源文件在开发仓库 `scripts/macos-management/`，测试在 `tests/test_macos_manager.py`。部署记录及本机服务信息不放进源码目录。修改先在仓库完成并测试，再同步管理入口。

在开发仓库运行管理逻辑自检，使用模拟服务，不停真实服务：

```sh
/usr/bin/python3 -B -m unittest discover -s tests -p test_macos_manager.py -v
```

在开发仓库同步到现有管理目录（不删除部署记录或本机信息）：

```sh
rsync -av --exclude '._*' scripts/macos-management/ "/Volumes/Adam/Mac mini M4 Server/Zeekr/"
```

实际健康验证使用“03_健康检查.command”。
