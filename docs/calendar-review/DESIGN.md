# 用车日历 · Operate

在现有极氪仪表盘视觉体系内扩展，目标是按天回顾和处理遗漏。适配用户在桌面查看月份、手机快速查看某天的场景，保留日间与夜间主题；不改变其他研究工具。

- 继承 `--paper`、`--ink`、`--line`、`--accent`、`--soft` 和夜间语义颜色。行程沿用绿色，充电和待补沿用暖色。日期和量值用等宽数字，不用装饰字体。
- 工具条选择月份和回顾日期。月摘要是一条有分隔的阅读/操作区域，含有效里程、涉及行程的日期数、已填实际充电费用、待补次数；不做四张孤立卡片。
- 月历使用连续七列格线、较低日格，主要内容按里程/花费/待补模式变化。浅深底色表达本月相对数值；空白和未来日期淡化，但说明归档缺失的含义。明确零保留数值，未知不显示零。
- 宽屏并列月历与当天时间线；1199px 以下纵排，600px 以下压缩日格与工具条。手机点击日期滚动到当天回顾。时间线保留整条事件、跨午夜、部分记录、未知地点与 SOC 电量估算的限定。
- 待补充电就地展开金额表单，日期和关联事件固定预填；其他已有字段原样带入保存。保存、取消、失败、版本冲突、读取、免费零值均有可见反馈。保存期间禁用日期和模式控件。
- 月份、日期、模式和已查询状态参与 URL 导航，坐标、地点名称、账单字段不进入 URL。采集说明默认收起；可打开当日快照或充电账本。

## 本轮验收

使用合成数据和本地服务，没有实车或外部地图请求。桌面与手机、深浅色、320px/390px/1440px、200% 缩放、可见文字对比度通过；保存和返回路径通过。没有新增生产位图资产。

## 用电成本扩展

月摘要增加用电成本入口，付款金额与消费成本分开。金额有未知部分时直接标明“仅已知部分”；每天与行程展示已知价格电量占有效耗电的比例。可靠停车片段在当天按需展开；月历用电成本模式显示部分/可估状态。历史回看 180 天，充电损耗计入电池成本，跨午夜归结束日；初始存量、缺金额、缺电表计量保留未知。
