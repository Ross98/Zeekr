# 单车行程与轨迹

用户已批准：只考虑这一辆车；按日期列出每趟行程，选中后查看对应路线；显示起止时间、时长、里程、电量变化；地图标记起终点、数据缺口并支持回放；显示行驶中、停车确认中、已结束；保留全天总览及独立的云端历史。

## 页面和状态

沿用现有明暗主题。日期和来源位于顶部，本地行程列表与地图详情分栏，窄屏单列。默认全天总览，不自动加载位置。单趟卡片显示时间、里程、电量和记录状态；选择行程不改变位置显示许可。采样详情折叠显示。

地图标记的是首末可用采样位置，不冒充未采集的实际出发/到达位置。间隔超过 180 秒、不可信点、时间缺失/倒退仍断开；显示可确定的时间间断，不猜原因，不补路线。行程事件完整性与路线采样质量分别说明。

手动逐点、播放/暂停、1x/2x/4x 步进回放。每秒一步是采样回放速率，不是实际车速。切日期、行程、来源、离页、隐藏位置停止播放；后台轮询保留行程、地图视角和采样位置。迟到请求不得覆盖新选择。

## 数据接口

新增只读 `GET /api/trips?date=YYYY-MM-DD&cursor=...`：返回 `events`、`next_cursor`、`active`。事件限定当前/已绑定车辆；离线仅有一辆本地车时允许回看，不开放页面选车。摘要仅有事件 ID、状态、时间、里程、电量、完整性，不含位置或私有报文。

扩展 `GET /api/tracks?date=YYYY-MM-DD&trip=<event-id|current>`。不传 trip 返回全天；传入已结束事件 ID 按完整起止时间读取，包含跨午夜部分。current 按持久化进行中行程边界读取。未知 ID、其他车辆 ID、非法时间须明确报错。仍限制 5000 点并说明截断。

路线保留 observations、segments、count、truncated；新增 gaps（start_time、end_time、duration_seconds、reason）和 quality（trusted_count、untrusted_count、unplottable_count、gap_count、segment_count）。无轨迹仍保留行程摘要。没有新位置查询、车控或通知操作；云端历史权限不在此轮实测范围。

## 验收

- 单趟/全天、跨午夜、当前行程和停车确认；拒绝其他车辆与未知行程。
- 摘要不含坐标，隐藏位置不请求路线或底图，隐藏后清空路线。
- 未知/不可信/长间断不连线；采样质量不声称实际 GPS 完整。
- 切换期间迟到请求、失败重试、后台更新、回放边界与离页清理。
- 明暗主题、320/390/1440 宽度，无横向溢出，键盘可用。

本轮实施和本地验收；部署另按发布流程处理。
