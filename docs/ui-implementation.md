依据：已批准的 `ui-design.md`，2026-09-17。

1. 先增加展示模型和轨迹行为测试，确认缺少实现时失败。
2. 增加保守字段解释、独立定位解析、受限权限 SQLite 存储与路线分段。
3. 增加仅本机 HTTP 服务、同源请求校验、手动刷新和显式启停采集。

5. 核查参考实现的历史轨迹能力；未取得可验证端点时准确显示未接入。
6. 执行离线回归、HTTP 集成、浏览器桌面/移动端验收，更新使用说明。
