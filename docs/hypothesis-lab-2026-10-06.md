# 假设与验证：先大胆猜，再找规律与反例

用户要求将取值频率、已知用车状态、实际操作对照与反例检查用于全部未确认参数。桌面入口为“用车研究 → 假设与验证”。仅研究本车保存的归档，不读取车辆云端，不自动把推断写进运行解码。

## 第一版假设

每次手动分析都为全公开目录生成第一版解释，明确标记“自动假设，未确认”。用户可改写后保存为本车参数核实记录中的“有疑问”。这些记录独立于解码器和通知，不覆盖已有人工字段确认或不适用记录。

| 字段类别 | 大胆起草的方向 | 后续论证 |
|---|---|---|
| 自动挡位 | 按用户指定 0=P、1=R、2=N、3=D | 行程、停车分布与实际换挡对照 |
| 电子驻车 | 0=释放、1=生效 | 驻车操作前后、行程切换、两种反例 |
| 使用模式 | 13=行驶、1=停放、2=充电相关、0=休眠或缺省 | 停车与充电分开看，检查切换延迟 |
| 开闭、激活、启用字段 | 0=关闭或未启用、1=打开或启用；其他值为细分状态 | 实际开关操作与原值变化，不能只凭名字确定 |
| 锁止字段 | 停车常见编码可能是锁止，行程编码可能是解锁 | 独立锁车和解锁操作，而非停车本身 |
| 其他状态编码 | 在目标场景集中的编码可能代表该功能生效 | 跨场景分布、状态切换、反例 |
| 一直为常量 | 未启用、缺省或本车不适用 | 找不同场景、核对车型适用性；不直接解释为关闭 |
| 数值字段 | 可能是名称对应的直接量值 | 核对单位、缩放、无效哨兵和实际读数，不把每个值当枚举 |
| 未返回字段 | 根据字段名称提出待验证方向 | 没有值时不能论证编码，保留未返回状态 |

只有用户已指定的四档映射作为运行解释实施。本工具生成的其他假设不会自动采用。

## 证据与反例

手动选择最多 31 天。新旧缓存按有效车辆时间去重；同时间取最后有效修订。异常、陈旧、时间倒退观测不参与论证。查询分日读取，最多 150000 条，超过限制要求缩小日期范围。

独立条件来自保存的行程、充电区间；行程中停住仍属于行程。排除这些活动后，相邻位置相同可作停车证据；缺失位置保留状态不明。使用事件覆盖的限制，尤其事件开始时间缺失、尚未结束或没有保存记录，直接说明。不能将未取得事件当作物理活动不存在的证明。

支持自选公开参数及原值作为独立对照，对照字段自身排除候选。自选参数的含义由用户核实；场景标签不会依赖待解释档位或充电编码，避免循环论证。

每条候选保留三类相邻观测窗口：状态与参数都变、状态变而参数没变、参数变而状态没变。超过 10 分钟的间隔、缺值或状态不明的窗口不用于变化论证。变化在同一观测窗口并不代表精确同时发生。按变化和有效样本量排序，仅为研究排队，不是含义概率。

每个方向最多列 8 对真实时间及原值；分布最多展开 20 种原值，其他数量单列。统计为有效时间样本数，不冒充时长比例。目标内外缺少其中一边样本、只有一种原值、未返回、时间缺口都有明确提示。

## 保存与边界

复用本车参数核实存储与版本控制，保存时要求匹配车辆、研究上下文、请求密钥和修订号。假设仅能以字段级“有疑问”保存；已有人工字段确认受保护。账号或车辆切换清空旧研究及页面草稿，迟到响应不覆盖新车辆。保存失败保留填写；可重新分析同步最新修订。

查询是只读操作，没有数据库迁移、原始数据回填、车辆刷新或通知发送。源码只保存方法和通用假设规则；真实研究载荷、坐标、车辆标识和密钥不提交。

本轮同时包括停车识别、有效更新时间去重和档位映射，发布还包含之前已提交的前舱盖、桌面状态总览。
