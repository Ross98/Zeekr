# 用车日历回顾与补账 · 本地验收

用户确认布局和范围后实施，验收后授权提交；本轮未部署。

- 月摘要展示有效里程及样本数、行程涉及日期数、已填实际充电费、待补充电。点击摘要切换日格指标；待补摘要定位第一个待补日期。
- 月历减少独立边框与空白，主要量值清晰展示，底色表达本月相对大小。桌面并列当天时间线；手机点日期滚动到当天回顾。
- 时间线读取已有本地地点命名，保留未知、跨午夜、片段、整趟里程和有效 SOC 电量估算。没有额外车辆或地理编码请求。
- 日历内可补实际充电金额，预填账单日期和关联事件。未关联或已关联但实际金额未知的记录可补；明确 0 元不算待补。编辑现有账单时保留来源、备注、桩端电量、电价、附加费、停车费和充电方式。
- 金额来自账本，按账单日期统计，仅计算实际充电费用，不含估算与停车费。里程及月事件数量按结束日期去重；跨午夜记录在涉及日期都展示，不按天分摊里程。用车日期数包含跨午夜涉及的日期。
- 保存使用账本的账号上下文、版本与写入保护。失败保留金额，重读后可核对再保存；保存期间禁用导航输入。月份、回顾日期、显示模式和查询状态纳入 URL，刷新/浏览器返回保持定位。

验证：新增数据口径测试先失败再实现通过；全量 Python 764 项通过，49.502 秒。新浏览器回归覆盖实际金额 0、未知金额、字段保留、冲突重试、键盘保存、URL 刷新/返回，以及深浅色、桌面/手机、对比度和 200% 缩放。后续文案和保存禁用状态改动经过功能回归。导航状态单测和 diff 格式检查通过。

本轮设计检查仅标记既有研究页签样式（insights.css 107 行，边框声明且实际 border-radius 为 0）；本轮新增日历样式无该发现，没有修改其他研究工具。预览数据均为合成数据，不是实车账单。
