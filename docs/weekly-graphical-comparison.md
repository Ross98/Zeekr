# 周报／月报图形对照

网页版沿用现有周报查询和日期筛选。首屏四组本期／上期横条展示里程、结束行程、观测时段、合格样本百公里电量估算；显示数值、差额及可计算的环比。耗电、结束充电、充入电量和充电实付放在每日里程图上方。每日双柱按星期（周报）或月内日期（月报）对齐，两期共享零起点刻度，点击本期日期筛选原有结束事件。

每组指标独立刻度。月内上期不存在的日期显示“无对应日”；未来、未知、实测零值分开。片段柱用警示色，有效片段仍计入已记录里程。进行中周期、无有效样本、上期为零不显示百分比；覆盖不同不等于真实用车增减。

实付从同一份当前稳定账号／车辆的有效账单快照汇总，按账单日期分到两期并排除未来账单。只汇总 `actual_cents`，不包含停车费、日常支出，不用 SOC 电量推算费用。没有已录金额为未知；已录免费账单为零。存在金额待补或充电事件未关联账单时，不算实付环比。账单原文、备注、身份不进报告响应。网页既有查询期间身份及个人记录版本复核继续生效。

原有地点回顾、观察、归档覆盖、出发时段和事件筛选保留在图表后。企业微信周期推送图片与发送时间不随此次网页改动变化。

验证入口：`tests/usage_report_analysis.cjs`、`tests/ui_usage_reports.cjs`（`DESKTOP_ONLY=1`），以及 `test_usage_reports`、`test_insights_api`、`test_readonly_analysis`。浏览器检查涵盖双期图、实付、卡片顺序、点击筛选、错误保留、明暗主题、桌面宽度和缩放。

下半页也使用同一套图形语言：观察指标及片段里程为两期横条；归档为逐日格图与读取次数横条；出发时段共用两期全局刻度；地点回顾为出发／到达横条。结束事件默认展示同类里程或充电时长、电量估算横条及 SOC 端点连线，原始容量等信息按需展开。SOC 连线只说明两个端点，不是连续过程或补造样本。保留筛选、翻页、自动洞察的按需展开和未知／零值区别。
