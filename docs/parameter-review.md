# 参数逐项核实

进入“参数详情”，选择参数，在右侧填写确认含义、实际观察、核实场景和备注，再点击“保存并下一项”。有有效读数的车辆参数均可正常读取、展示和参考；“未知”项不在参数页展示，也不计入核实进度，有效值返回后自动恢复，已有核实记录保留。“待核实”只是解释依据的提示，不是使用权限。核实操作只保存服务端注释，不向车辆发送控制指令。

## 核实范围

- **当前原值的含义**：默认选项，适用于枚举和状态码。例如确认 `0` 的含义，并不会自动确认 `1`。遇到新原值，显示“部分确认”，可从右侧已保存记录查看旧值的解释。
- **整个字段**：用于数值参数含义、单位和换算说明，或标记字段不适用。数字编码也可能是枚举，不能只因原值是数字就选择整个字段。
- 单位和换算方式只作记录，不执行用户输入的公式，不修改其他页面或通知使用的解码规则。

顶部统计显示**人工核实进度**。系统原有的“本车已核对”“社区解释”等依据单独保留；首次使用时没有人工记录的参数均属于“待核实”。“已确认”表示当前原值或数值字段规则已有人工确认，不代表已覆盖这个字段的全部可能枚举。

## 保存、修改与撤销

- 保存后可刷新网页或换浏览器继续；记录按车辆隔离。
- 后台刷新保留当前填写内容和核实样本。新原值出现时提示变化；保存或放弃草稿后，可点击“使用最新值核实”。
- 切换参数或应用内页面会保留当前浏览器中的草稿；整页重新加载或关闭网页不会保存草稿，请先保存。
- “暂时跳过”切到下一项，不改核实状态。
- “清除本条确认”只删除当前选中的值映射或字段规则。“撤销上次操作”恢复本次浏览会话中的上一步保存或清除。
- 同一车辆的记录被另一页面更新时，保存会提示冲突并保留填写内容。核对最新记录后再次保存；不会静默覆盖。
- 保存失败会显示错误并保留草稿，不会将其显示成已保存。

## 数据位置

记录保存在轨迹数据库同目录的 `field-reviews.sqlite3`，按车辆摘要、完整字段路径、核实范围与原值区分。文件与车辆解码、通知处理独立；备份时请包含此文件。核实时的原值、整车缓存时间与保存时间一并记录，整车时间不代表子字段独立采集时间。

## 本地验证

```sh
python3 -m unittest discover -s tests
node tests/ui_field_review_rules.cjs
node tests/ui_field_reviews.cjs
```

浏览器验证使用临时服务、合成车辆和临时数据库，不访问真实车辆账号。需有 Playwright；可通过 `CHROMIUM_EXECUTABLE` 指定本机 Chromium。

## 中文词典与车型适用性

参数说明现使用独立术语词典。点击一项可查看单位、推测依据、车型／配置适用性和来源；搜索也覆盖这些说明。车型参考基线为 2023 款极氪 001 WE86 四驱，年款配置不代表本车选装或功能权益已确认。资料核对详见 [车型适用性记录](parameter-applicability-2023-we86.md)。

词典不包含历史快照读数，不会自动填写或覆盖人工确认。车辆档案采用独立路径；身份标识和精确坐标不进入核实列表，空值仍隐藏。
