# 参数研究与核实整合

桌面“用车研究”内的三个参数入口合并为“参数研究与核实”。统一清单按公开字段路径关联当前缓存、历史假设、实验记录和人工结论，不再分别选择三次参数。清单保留本次未返回字段；缺少有效原值时不提供直接人工确认，仍可研究历史。

详情按“看参数、分析证据、操作验证、写结论”组织，步骤入口与下一步提示固定在详情顶部。一次只展示当前步骤；核实进度、术语来源和完整原值分布按需展开。选择参数时优先展示有效值，并保持当前选择可见。历史分析仍手动查询全目录，结果保留当前选定参数。

分析页不再使用泛化的默认停车假设，也不再提供第二套保存表单。“采用假设写结论”将解释、支持与反例依据带入同一核实编辑器，默认有疑问。已有人工字段确认或不适用记录受保护，不能被自动假设覆盖。未返回字段允许保存和继续修改待核实解释，取得有效值或历史实验样本后才能人工确认。

操作验证默认展示关联记录，点击新建才显示表单。先记录实际动作与时间，再选择前后样本；新建不默认填入当前时间作为实际动作时间。实验默认只选择当前参数的变化字段，跨参数实验仍可用。编辑中的实验在切换清单后保留原参数、样本和备注，包括尚未比较的草稿。已保存实验冻结原始摘录，可直接点击“用前／后样本写结论”。

步骤切换保留结论与实验草稿；浏览器返回保留步骤。详细历史与场景提供“返回参数研究”，恢复原参数、列表筛选和步骤。账号或车辆切换清空旧证据与草稿。步骤是可返回的操作顺序，不是必须逐项完成的审批门槛；已有实际观察可直接写结论。

复用原核实、假设和实验接口及存储，无迁移，不修改运行解码或通知。账号或车辆切换清空旧草稿与证据，迟到响应不覆盖新车辆。旧 `fields`、`hypotheses`、`lab` 工具链接统一打开本页，并展开对应内容。

本地验证使用一次性合成车辆与归档。覆盖统一选择、217 个公开字段、假设保存与人工确认保护、实验保存及证据核实、步骤与浏览器返回、历史往返、草稿归属、未返回假设保存后继续编辑、车辆切换、旧链接和桌面日夜主题。工作流截图位于 `/tmp/zeekr-parameter-flow-qa/`。本文件不代表已部署或真实车辆验收。
