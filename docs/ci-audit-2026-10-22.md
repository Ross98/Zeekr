# CI 审计 — 2026-10-22

审计部分记录最初盘点，后续本地修复见执行状态。历史红灯、旧排除项数量不等于修后结果。依据当前 `140306f370a19e9f2b9e44db1928b2c12123b1ed` 的代码和 GitHub 实查；默认分支 main 为 `b3a1119fe038665741800dfd841cf8b80ccc9d78`。旧审计文档只作历史背景，不当当前证据。

## 结论

现有 CI 主体有用，应修补而非重建。没有证据支持直接删除整个工作流或 Python／Desktop 任一任务。最急的是最新 Desktop 红灯、失败证据没有落盘，以及生产已转 macOS、CI 仍只有 Ubuntu 的覆盖缺口。

## 修复执行状态

本地实现：增加 macOS native tests、Workflow checks；执行器增加每文件超时、独立失败后继续、POSIX 进程组及脱离进程组的后代清理、JSON 汇总；npm test 运行 unit+smoke+review；语法检查扩至 scripts/tests。所有常规产品浏览器脚本在页面销毁前收集证据，新增故意失败的共享夹具回归。存储、紧凑日历、周报、纯桌面记住登录接入例行检查。当前 119 个 CJS：70 执行、49 排除；排除项必须填写 kind 和 review_when，保留辅助／手工／容量工具，明确剩余业务覆盖债务的复核条件。

地图专项控制取节点到按鼠标之间的自动轮询窗口；强制真实 HTTP 轮询、按住保留节点、放开重绘、坐标实际移动与保存再读、跨账号与导航失效断言全部保留。自动轮询在其余阶段正常运行，包含跨标签同步。周报测试与现行手动查询契约一致：切换周期先清旧结果，再点击查询。

原生测试揭示并修复资源 CPU 统计缺陷：本机 ps -S 没有累计已回收子进程 CPU。改用 proc_pid_rusage 的自身与子进程累计时间，按 Mach timebase 换算；前后核对成员及原生出生时间，不能用不完整窗口证明恢复。回归使用真实短 CPU 子进程，不再只验证合成数值。

Mac 发布 preflight 增加确切 SHA 最新 CI 与四项必要任务门禁，失败在停服和写发布记录前阻止切换。已用当前 GitHub 红灯提交验证拦截。主分支保护 payload 已准备，未写远端。修复尚未提交或 push，新四项工作流和远端规则的 GitHub 验收仍待完成；不把本地通过称为 GitHub 全绿。下方审计表与 52 项旧排除清单保留为问题来源。

macOS 托管 runner 使用明确的 macos-15 标签，依据 [GitHub runner 文档](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)。工作流校验使用上游 actionlint 固定 v1.7.12，本机下载包已与该版本官方 checksum 核对；参见 [actionlint 安装说明](https://github.com/rhysd/actionlint/blob/main/docs/install.md)。GitHub macOS job 为 Python3.12；生产3.9.6兼容性继续由本机原生专项和实际服务用户候选验证证明，不混称为完全相同环境。

## 需要新增

1. **macOS 原生 CI（P1）**：在隔离的 GitHub 托管 macOS 环境验证真实 Darwin CPU tick、`ps -S` 解析与进程回收计数、sysctl 压力读取、Foundation 容量读取；错误／未知路径仍用合成注入。现 `test_resource_monitor` 的 NativeSampler 用替身，macOS storage/release 主要用 mock，Ubuntu 通过不能证明原生调用成功。Mac mini 实际 `/usr/bin/python3` 是 3.9.6，GitHub 是 3.12；要明确兼容基线，不能把随意选择的 macOS+Python 等同生产。现有实际服务用户候选全量检查继续保留。
2. **发布前的确切提交 CI 门禁（P1）**：先 push 指定提交并等待其所需 checks 成功，再允许生产切换；保留生产候选全量／哈希／认证／备份门禁。现流程可以先上线再 push，GitHub 随后变红；最新提交就是例子。分支保护只管 main，不能代替发布工具检查开发分支的确切 SHA。
3. **主分支必要检查规则（P1）**：为 main 配置必要的 Python、Desktop，macOS 加入后再设为必要项；具体是否允许本人绕过须明确。此次只给建议，不修改远端规则。
4. **桌面认证关键路径（P1）**：`ui_remembered_auth.cjs` 仍排除且含无条件 390/320 视口；先拆成纯桌面，验证登录、7/30 天记住、重启、IP／浏览器绑定、退出撤销，再纳入例行或受影响改动检查。现 `ui_vehicle_login`、Python auth 测试有价值，但不等于这条完整记住登录浏览器链已被 CI 覆盖。
5. **工作流与执行器静态检查（P2）**：增加 actionlint，以及 scripts/*.cjs 的语法检查；前者拦无效表达式／步骤配置，后者覆盖目前只检查 static/*.js 的盲区。版本要固定，不能运行时取最新版。
6. **清单覆盖债务跟踪（P2）**：逐项复核剩余业务排除项，按实际产品风险分批准入，优先认证、存储、日历／周报、费用与充电异常；不恢复移动端，不为凑覆盖率重跑所有研究功能。重复断言合并需先证明替代覆盖。
