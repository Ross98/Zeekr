# README 截图

这些 PNG 于 2026-10-26 从当前仓库的桌面界面重新生成。截图服务使用临时目录、合成会话与测试数据库，不读取生产账号或业务库；车辆名称、日期、金额、行程和地点均为演示数据。每张图的侧栏都带有“合成数据截图／非真实车辆记录”标记。

- `local-trips.png`：连续出行链与 24 小时出行节奏。
- `charging-review.png`：月度充电回顾与费用分析。
- `costs-overview.png`：分类环图、支出明细与费用趋势。
- `usage-report.png`：图形化两期对照，选用自然月展示里程、耗电、充电与实付变化。
- `charging-ledger.png`：统一补账与账单管理。
- `expense-ledger.png`：生活支出分类图与流水。
- `trip-tags.png`：标签分布、逐趟标注与分析。

## 重新生成

在仓库根目录完成浏览器测试依赖安装后运行：

```bash
npm ci
npm run browser:install
DESKTOP_ONLY=1 node scripts/capture-readme.cjs
```

脚本复用 `tests/insights_fixture.py` 和 `tests/recall_fixture.py` 的隔离测试服务，车辆客户端被测试替身禁止调用。浏览器使用新建的空白上下文，只允许请求自身的临时回环服务；外部请求被阻止，第三方请求清单必须为空。不打开定位与地图，不发送真实通知。

图片固定为 1440 × 1500 的夜间主题桌面视口，不做手机截图。报告比较时间固定，数据来自既有合成 fixture；没有改写真实记录或用静态 HTML 冒充页面。可通过 `CHROMIUM_EXECUTABLE` 指定已安装的 Chromium。

生成前检查可见文字中的手机号、车牌、VIN、凭据样式、精确坐标及测试专用隐私占位符；同时检查合成标记、水平溢出和第三方嵌入。合成标记独立于页面轮询刷新，避免被重新渲染移除。生成后仍须逐张查看，确认没有隐私内容、加载错误或关键内容遮挡。

PNG 是页面视口截图，长页面下方内容需要滚动，不宣称一张图覆盖整个页面。图片不附带浏览器地址栏、真实车辆照片或账号登录表单；本轮只更新截图、说明和重拍脚本，不修改或重启生产服务。
