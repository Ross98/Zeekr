# 最近道路＋最短路径接入

用户选择评分表第一方案；用标准库实现保持轻量。修改行程地图；用户随后已授权提交与部署，未授权推送。

1. 保留 TrackStore 的观测、可信片段、缺口及数据库。新增 `road_matching` 返回字段；每个已有片段独立匹配，绝不跨现有间断。
2. 使用本地只读 SQLite 道路库，RTree 查候选、单行图最短路径。区域 OSM 快照离线建库；不在请求中联网。数据存在会话目录 road-networks/，不提交用户轨迹。
3. 独立进程限制内存256MB、CPU6秒、墙钟8秒、nice10。一次只跑一个工作进程，两个结果缓存；道路库变化或源片段变化使缓存失效。超过1500源点、无路网、繁忙、超时或错误均保留原始连线。
4. API 返回 WGS84 推断线和覆盖的源点跨度。UI 沿推断道路绘制；未覆盖部分保留原虚线和全部源点，说明算法推断不是实走确认。原坐标不被吸附点替换，回放和稀疏统计仍使用原采样。
5. 测试先行：可信/坐标过滤、已有缺口、单行/拐角裁切、无匹配、缓存与失效、限额/故障/并发、API边界与浏览器绘制/回放/刷新。再用原六条路线验回归，资源单独量。
6. 路网不含禁转关系；局部平面投影，10公里路径搜索上限。只推断地图，不重算里程、时间、费用，不加入通知图片。
