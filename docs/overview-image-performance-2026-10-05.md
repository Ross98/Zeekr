# 总览图片性能修复（实现与本地验证）

用户批准缓存、图片压缩、刷新节点复用与地图复用方案。实现基线为 `8b142c7`；本地验证阶段未提交、推送或部署，未访问真实车辆、地图供应商或发送通知；后续发布状态见同日 overview-image-release 文档。

## 原因与实现

- 原静态图片统一响应 `no-store`，不能跨页面载入复用。旧图片改为 `private, no-cache` 并支持 ETag/304；六份带内容哈希的新 WebP 使用 `private, max-age=86400, immutable`。请求仍先通过登录门禁。API、位置图片、脚本保持 `no-store`。
- 保留原始 PNG/SVG 和车型配置/发布门禁。WebP 使用原图生成，不添加/重绘内容；透明通道保留。首页裁切 `(70,100,1130,550)` 对应原 SVG viewBox，详情保留整图，俯视图保留方向。每类提供原显示分辨率与半尺寸版本，质量85、LANCZOS缩放、WebP method6；生成工具是开发环境 Pillow，生产没有新增依赖。
- 首页车图 eager/high，其他车型图 lazy/async；尺寸属性保留显示比例，srcset 按视口选图。
- 在惰性 template 中构建新内容；先将 fragment adopt 到当前 document，再移入已有图片，避免跨 document 移动重启 `no-store` 请求。相同 src/srcset 复用节点；其他工作区/焦点/滚动保留逻辑不变。
- 地图版本仅包含有效性、坐标、坐标系、可信状态，车辆更新时间独立展示。同账号车辆、相同位置和缩放复用当前图；账号/车辆/服务上下文变化先清旧图；新图完成后替换，加载期间标明上次底图，失效位置清除。位置图不写浏览器磁盘缓存；服务器仍为账号车辆隔离的有界五分钟缓存。
