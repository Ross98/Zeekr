# 中国区老款 001 最小读取程序

> 历史设计，保留 2026-09-17 的阶段决策；当前规则见 [PRODUCT.md](../PRODUCT.md) 与 [DESIGN.md](../DESIGN.md)。

2026-09-17。根据已批准的首阶段方案实现，不包含 iOS、HTTP 服务或远程控制。

## 选择

采用 Python 3.9 标准库 CLI，直接在现有 Mac 上运行，无需升级系统 Python。Home Assistant 集成依赖较重；海外 SDK 的认证不同，均不作为运行依赖。

模块：client 负责两个网关的签名、认证和读取；storage 保存本地会话；CLI 提供 login、vehicles、status、logout。登录支持本机隐藏输入 JWT 或短信验证码。先取得 JWT，再换取 YIKAT_NEW 授权码和 GW2 accessToken。只读取关联及分享车辆列表、缓存车辆状态，不主动唤醒车辆。

成功标准：CLI 可以运行；离线测试验证请求签名与实际字节一致、失败响应不会被当作成功、非法 VIN 在发请求前被拒绝、凭据文件只有当前用户可读写。真实成功必须以用户账号读取结果为准。

## 限制

社区接口不是官方承诺，可能失效。GW3 源码包含未经证实的候选端点和授权恢复尝试，本版不采用。GW2 状态使用 latest=Local，可能是旧缓存；输出保留服务端结构和时间字段，不把本机读取时间当作车辆更新时间。Token 到期需重新登录；不自动重新登录、反复请求或自动刷新。

## 执行顺序

1. 固定来源版本并记录端点。
2. 先写签名、边界、存储和 CLI 测试，确认失败。
3. 实现仅含上述端点的客户端和本地会话。
4. 跑离线测试、命令帮助和未登录检查。
5. 交付本机交互命令；账号联调等待用户本机登录。
