# 夜间模式实施与发布记录

用户已确认 `night-mode-design-2026-09-19.md` 并授权实施、部署。

## 实施顺序

1. 为主题偏好、系统覆盖、存储异常、多标签同步写测试，确认未实现时失败。
2. 接入首屏主题脚本、登录/仪表盘外观入口和公开静态资源白名单。
3. 将现有配色接入语义变量，保留日间颜色回退；提升小字与触控面积，重新排布手机车辆详情。
4. 为充电图坐标/断线/独立点写测试，再实现刻度与单位；复用同一坐标转换用于刻度与曲线。
5. 浏览器与后端回归、审查改动、候选版本检查、备份、切换及线上验证。

## 已实现

- 跟随系统、日间、夜间；首屏绘制前解析偏好；同浏览器标签同步；存储受限时降级到当前会话。
- 登录和仪表盘共用主题，原生日期/选择框随 color-scheme 改变。
- 文字、警告、未知/错误、表格、复核、充电、存储管理、地图控件覆盖夜间配色。
- 普通小字最低 13px，技术字段路径 12px；单位保持 15–16px，手机重排。
- 图表刻度、北京时间与单位、独立点；不同片段及空值不连线；AC/DC 图例与柱色对应。
- 地图瓦片与车辆图片保留原色；没有新增地图源或主动车辆查询。
- 修复浏览器测试在北京时间午夜后使用“今天”查不到 20 分钟前合成缓存的日期问题。

## 验证

- Python 全量 282 项通过。
- 主题逻辑与图表逻辑测试通过；新增测试均先观察到失败后实现。
- 原有八组浏览器回归通过；充电页另在夜间通过。
- 夜间总览、车辆、能源、地图、轨迹、参数、设置、更多八页在 1440/1280/1024/390/320 CSS 宽度检查布局与可见文本对比度；合成数据，不能当真实车况证据。
