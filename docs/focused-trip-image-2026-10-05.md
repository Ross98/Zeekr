# 行程推送图：路线优先

用户批准无地名背景、仅起点名称、自动旋转铺满、轻虚化版本，授权 commit 与部署。

- 新的 1068×886 PNG：中文排版、四项原报告指标、深绿采样线、白色描边、A/B 采样边界、北向箭头。
- 以可信采样片段绘制，保留缺口；不增加道路推断、不补采样、不重算里程或能耗。时间仍是缓存观测时间，连线不表示已确认实走道路。
- 遍历 -90°..90° 找等比例最大缩放，保持片段、相对距离和边界；预留标记/文字边距，旋转北向箭头。不横纵拉伸。
- 背景从既有区域 SQLite 道路库只读获取，只读取道路几何，不读取道路名称，不含商铺/地名/楼栋层。背景半尺寸抗锯齿绘制与插值放大，降低对比。显示 OSM attribution。
- 起点优先使用无参考地点标记的已存地址；缺失时仅查询首个可信采样点的地址，失败显示“起点名称未记录”。终点只有 B 标记。名称限制长度，常用 CJK 字形之外显示替代字符。
- 没有覆盖、GCJ-02 采样或道路库损坏时背景可为空，仍绘制可信轨迹并标明“本区域无道路背景”；不会混合 WGS84 道路与 GCJ-02 轨迹。未知/混杂坐标系、无可信片段或超过点数上限均停止生成，发送器不调用。
- 渲染独立 Python worker，nice 10，Linux 256 MiB 地址空间、6 秒 CPU、8 秒墙钟。最多 1500 源点、8 个区域（单库≤64 MiB）、10000 背景道路、60000 顶点、1.5 MB 输入、2 MiB 输出。道路可截断，轨迹不截断。
- 运行时仅标准库；复用已部署道路库。Noto Sans SC 字形压缩包约 3.8 MiB，离线生成，无服务器 Pillow、字体引擎、无头浏览器或新常驻地图服务。字形及许可在 assets/trip-font；tools/build_trip_font.py 是离线工具。
- Monitor 的发送顺序、重试、uncertain、去重和既有 sent 事件不改；旧注入式 PNG 渲染器兼容现有测试。

本地生产渲染器真实历史行程只读预览在私人可视化目录；不进 Git，不发送测试通知。最终验证、实际发布与回滚见 [发布记录](focused-trip-image-release-2026-10-05.md)。孤立可信点单独绘制，不跨缺口连线。
