# 参数研究与核实整合

桌面“用车研究”内的三个参数入口合并为“参数研究与核实”。统一清单按公开字段路径关联当前缓存、历史假设、实验记录和人工结论，不再分别选择三次参数。清单保留本次未返回字段；缺少有效原值时不提供直接人工确认，仍可研究历史。

详情上方保留中文解释、单位、术语依据和人工核实记录。下方按需展开“历史假设、支持与反例”和“关联实验”。历史分析仍手动查询全目录，结果保留当前选定参数；编辑推理草稿后切换参数再返回，草稿保留。已有人工字段确认或不适用记录立即保护，不能被自动假设覆盖。

实验默认展示当前参数的记录，并只选择当前参数的变化字段。勾选“跨参数实验”可处理同一动作涉及的多项参数。编辑中的实验在切换清单后保留原参数、样本和备注；新建实验采用当前参数。已保存实验仍冻结原始摘录，可带前或后样本直接核实。

复用原核实、假设和实验接口及存储，无迁移，不修改运行解码或通知。账号或车辆切换清空旧草稿与证据，迟到响应不覆盖新车辆。旧 `fields`、`hypotheses`、`lab` 工具链接统一打开本页，并展开对应内容。

本地验证使用一次性合成车辆与归档。覆盖统一选择、217 个公开字段、假设保存与人工确认保护、实验保存及证据核实、草稿保留、车辆切换、旧链接和桌面日夜主题。截图位于 `/tmp/zeekr-parameter-workspace-qa/`。发布需另外取得明确授权；本文件不代表已部署或真实车辆验收。
