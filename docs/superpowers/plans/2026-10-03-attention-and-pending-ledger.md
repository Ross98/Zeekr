# 首页异常提示与充电待补账

范围：用户已确认首页异常提示和待补账；路线对比及其余建议后续处理。本轮不部署或推送。

1. 首页复用本地状态，正常隐藏。账号异常优先，其次后台／采集、最近通知投递问题、缓存时间。车辆时间超过现有监控的 3 分钟时效窗口只提示缓存过旧；缺失／超前时间明确显示。提示可分别打开账号、数据质量诊断、通知详情，不新增车辆请求。
2. 账本复用当前月份的未关联结束充电事件（含片段）。显示待记账数，展开分页列表；点击预填北京时间结束日期和事件，金额／计量值留空，焦点到金额。
3. 保存继续使用账号与车辆上下文、修订号校验。刷新数量并保留月份、待补列表分页及返回位置；删除／恢复／撤销同步数量。普通编辑行为保持。
4. 先写浏览器行为测试并确认失败，再实现。验证健康隐藏、缓存时间、账号、后台失败、双通知渠道去重、跳转、补账预填／零值／保存／撤销／草稿冲突保护。
5. 跑相关 Python 与浏览器回归；批量检查桌面／手机、日夜主题和键盘焦点。最后检查复用与简化、差异及语法。不覆盖工作区已有修改。
